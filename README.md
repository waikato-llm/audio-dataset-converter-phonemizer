# audio-dataset-converter-phonemizer
Integrates the [phonemizer](https://github.com/bootphon/phonemizer) library and its various backends.

espeak supports the following languages:

https://github.com/espeak-ng/espeak-ng/blob/master/docs/languages.md


## Installation

Via PyPI:

```bash
pip install audio_dataset_converter_phonemizer
```

The latest code straight from the repository:

```bash
pip install git+https://github.com/waikato-llm/audio-dataset-converter-phonemizer.git
```
